# RedPen 프론트

Vue 3 + Vite 단일 페이지. 실제 FastAPI 검토 API를 호출하며, 화면은 현재 고정 규정·저장된 공시 샘플 기반의 AI 1차 의견을 표시한다. 원천 검증과 RAG·라이브 MCP 조회는 아직 연결하지 않았다.

## 개발

프로젝트 루트에서 FastAPI를 실행한다. 모델·추적 설정은 환경변수 또는 `.env`에서 로딩한다.

```sh
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

다른 터미널에서:

```sh
cd web
npm install
npm run dev
```

Vite의 `/api` 프록시는 `http://127.0.0.1:8000`을 사용한다.

## 데모

```sh
cd web
npm run build
cd ..
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`http://127.0.0.1:8000/`에서 FastAPI가 Vue 빌드를 직접 서빙한다. 별도 Nginx나 프론트 컨테이너는 필요 없다.

## 화면 흐름과 제약

- 광고 입력 → 공시 상품 선택(선택 사항) → 검토 시작 → SSE 작업 상태 → 실제 리포트.
- 모델은 서버에서 설정한다. 브라우저에는 API 키를 전달하지 않는다.
- 현재 규정 샘플은 제22조 하나이며 기준일은 2026-10-21이다. 다른 기준일은 명시적으로 거부한다.
- 98개 공시 상품은 저장된 예금·적금 스냅샷이며 실시간 상품 목록이 아니다.
- 하이라이트는 추출된 원문 위치를 사용한다. 반복·겹치는 문구는 임의로 위치를 확정하지 않는다.
- 판정·근거·금리 수치는 API 응답을 표시한다. 원천 검증 완료로 표현하지 않는다.
- 동의·기각은 화면에서만 반영한다. 서버에 저장하지 않는다.
- 실행 중 새 검토는 비활성화한다. 탭을 닫아도 이미 시작한 서버 작업은 계속된다.
- SSE는 연결 유지 중 자동 재연결과 Last-Event-ID 재전송을 지원한다. 페이지 새로고침 복구는 아직 지원하지 않는다.
- 서버는 단일 프로세스, 동시 검토 1건, 최근 이력 최대 30건인 메모리 데모다. 서버 재시작 시 이력이 사라진다. `--workers`를 늘리지 않는다.
