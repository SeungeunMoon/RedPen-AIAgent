# RedPen 프론트 목업

Vue 3 + Vite로 만든 광고 사전심의 화면입니다. API, AI 심의, 데이터 저장 없이 고정 예시 데이터와 브라우저 메모리만 사용합니다.

```sh
cd web
npm install
npm run dev
```

기본 화면은 예시 리포트입니다. `새 검토` → 문안 입력 또는 `예시 불러오기` → `예시 검토 시작`으로 진행 화면을 볼 수 있습니다. 입력 내용과 관계없이 같은 예시 판정을 표시합니다.

원문 하이라이트, 판정 펼치기, 위험도 필터, 수정안 미리보기, 동의·기각은 화면 탐색용입니다. 금리·상품과 근거 문구는 가상 데이터이며 실제 금융·법률 판단에 사용할 수 없습니다.

빌드 확인: `npm run build`

데모에서는 `web/dist/`를 FastAPI가 직접 서빙합니다. 별도 프론트 컨테이너나 Nginx는 사용하지 않습니다. 현재는 목업 단계이며 FastAPI 서빙은 아직 구현하지 않았습니다. [프로젝트 구조와 실행 방식](../docs/프로젝트%20구조와%20실행%20방식.md)을 기준으로 연결합니다.
